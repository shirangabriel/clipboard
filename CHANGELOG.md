# Changelog

All notable changes to Clipboard will be documented in this file.

## 0.1.2 - 2026-06-07

- Added Sparkle-powered in-app update checks.
- Added a native `Check for Updates...` app menu command.
- Added update controls to the native Settings window.
- Marked the Homebrew cask as self-updating for future app releases.

## 0.1.1 - 2026-06-07

- Moved app preferences into the native macOS Settings window.
- Added bundle version metadata for the macOS About panel.
- Kept the menu bar popover focused on clipboard actions.

## 0.1.0 - 2026-06-07

- Initial public release.
- Added macOS menu bar clipboard history.
- Added custom user sections.
- Added speed-dial favorites.
- Added keyboard shortcuts for opening Clipboard and copying favorites.
